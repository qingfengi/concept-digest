# Concept Digest

Chrome 侧栏概念学习工具：输入概念或读取网页选词，向用户配置的 OpenAI 兼容模型请求解释，把结果及衍生关系保存为本机概念树。

## 使用

1. 打开 Chrome 扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选中本目录。需要 Chrome 116 或更新版本。
2. 打开扩展设置，填写自己的服务地址、模型名称和密钥。服务地址支持根地址或以 `/v1` 结尾的地址；公开服务须使用 HTTPS，本机服务允许 HTTP。
3. 点击扩展图标打开侧栏，输入概念后选择“解释并保存”。在普通网页选中文字后，也可在侧栏点击“读取网页选词”，再决定是否发送解释请求。
4. 点击衍生概念继续理解；已保存记录可重新打开、删除整条分支或导出 Markdown。

## 存储与权限

- 概念树和设置保存在 `chrome.storage.local`，不使用云同步。扩展卸载或浏览器清除扩展数据会删除它们，可提前导出概念树。
- 密钥保存在本机浏览器扩展存储中，不宣称系统级加密。内容脚本无权读取存储，设置页只取得掩码；新密钥保存成功后输入框清空。
- 请求只在用户点击解释时发送。发送内容是概念及其父概念路径，不自动发送整篇网页。
- 扩展的网页权限用于划词和访问用户自定义模型服务；网页内容脚本只能保存选词，不能取得密钥或直接请求模型。
- 浏览器内部页等不允许内容脚本的页面无法划词，仍可直接在侧栏输入。
- 解释由模型生成，可能不准确。网络或格式错误会显示失败，失败不会写入空白概念节点。

## 并发与验证

模型请求可以并行执行；概念树读改写会按顺序提交，并在提交时重新读取。删除父概念后，迟到的子概念请求不会复活父节点或留下孤儿记录。

需要 Node.js 22 或更新版本执行测试，无额外依赖：

```text
npm run check
npm test
```

单元测试模拟 Chrome 消息、存储及模型请求，不读取账户配置、不调用真实模型。
